# 폰 스크린골프 — 안드로이드 앱 (USB 카메라 직접 연결)

## 왜 앱이 필요한가
안드로이드 브라우저(Chrome)는 **시스템 카메라로 등록된 카메라만** 볼 수 있습니다.
OTG로 꽂은 USB 카메라는 대부분의 휴대폰에서 시스템 카메라로 등록되지 않기 때문에 웹페이지에서는 보이지 않습니다.
"USB Camera" 같은 앱이 영상을 보여주는 것은 **앱 안에 USB 카메라 드라이버(libusb + libuvc)를 직접 넣고** USB 통신으로 영상을 읽기 때문입니다.

이 앱도 같은 방식(UVCAndroid 라이브러리)으로 USB 카메라를 직접 열고,
기존 웹앱(`app/src/main/assets/www/index.html`)을 앱 안에서 실행해 밝기(Y) 프레임을 넘겨줍니다.
화면·물리 엔진·검출 로직은 웹 버전과 동일합니다.

## APK 만드는 방법 (둘 중 하나)

### A. Android Studio (PC)
1. Android Studio(최신 버전) 설치 → **Open** → 이 `android` 폴더 선택
2. Gradle 동기화가 끝나면 휴대폰을 USB 디버깅으로 연결하고 ▶ Run
   - 또는 메뉴 **Build → Build APK(s)** → `app/build/outputs/apk/debug/app-debug.apk`

### B. GitHub Actions (PC에 아무것도 설치하지 않음)
1. GitHub에 새 저장소를 만들고 이 `android` 폴더 내용을 그대로 올립니다
2. **Actions** 탭에서 "Build APK" 작업이 자동 실행됩니다 (약 5분)
3. 완료된 실행 → **Artifacts → ScreenGolf-debug-apk** 를 내려받아 압축을 풀고, 휴대폰에 APK를 설치합니다
   (설치 시 "출처를 알 수 없는 앱 허용" 필요)

## 사용 방법
1. **다른 USB 카메라 앱은 완전히 종료**하세요 (USB 카메라는 한 앱만 열 수 있습니다)
2. 앱 실행 → 카메라 탭 → 카메라 목록에서 **🔌 USB 카메라 (앱 내장 UVC 드라이버)** 선택
3. 해상도 선택 → **카메라 시작** → ① 카메라 권한 허용 ② USB 접근 권한 허용
4. 미리보기에 영상이 나오면, 공을 탭해 기준을 잡고 스윙합니다
   - 상단 정보줄의 `수신 fps`(카메라가 보낸 프레임)와 `처리 fps`(분석한 프레임)를 확인하세요
   - `버림` 숫자가 계속 늘면 설정 → 처리 해상도를 320으로 낮추세요

## 구조
```
USB 카메라 ──(libusb/libuvc, UVCAndroid)──▶ MainActivity.kt
   NV21 프레임 → Y(밝기) 평면만 추출 → 정수배 축소 → [w,h,타임스탬프ns,픽셀]
   ──(WebMessagePort, ArrayBuffer)──▶ WebView 안의 웹앱 (검출·물리·3D 필드)
   ◀── "ack" (처리 완료 신호, 최대 3프레임까지 대기 후 초과분은 버림)
```
- USB 전송 지터는 웹앱의 "USB 타임스탬프 보정"(설정 탭)이 프레임 간격을 추정해 보정합니다.
- 웹앱을 수정했다면 `index.html`을 `app/src/main/assets/www/`에 덮어쓰고 다시 빌드하세요.

## 문제 해결
| 증상 | 확인할 것 |
|---|---|
| "USB 카메라를 찾지 못했습니다" | OTG 젠더/케이블, 다른 카메라 앱 종료, 카메라 재연결 |
| 권한 창이 안 뜸 / 바로 거부 | 설정 → 앱 → 폰 스크린골프 → 권한 → 카메라 허용 후 재시도 |
| 열렸지만 화면이 검정 | 다른 해상도 선택(특히 640×480), 전원 공급이 약하면 유전원 USB 허브 사용 |
| 처리 fps가 낮음 | 처리 해상도 320, 카메라 해상도 640×480 |
| 빌드 오류 | 오류 메시지 전체를 복사해 알려주세요 (라이브러리 버전별 API 차이일 수 있음) |
