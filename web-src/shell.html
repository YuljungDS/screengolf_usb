카메라를 시작하세요.
공 인식 — 정해진 거리(0.3~0.5m)에서의 골프공 크기, 윤곽이 원인지, 구 특유의 명암이 있는지로 공을 고릅니다. 흰 종이·매트 흰 줄·큰 흰 원은 무시합니다. 처음 한 번 미리보기에서 공을 탭하면 실제 공 크기를 학습해 더 정확해집니다.
설치 — 카메라는 측면·비스듬·공 뒤(후방) 어디든 됩니다. 측면이 가장 정확하고, 후방은 공이 멀어지며 작아지는 크기로 거리를 재므로 조금 덜 정확합니다. 공 지름이 화면에서 60px 이상 보이게 가까이(0.4~0.8m) 두세요.
📐 각도 보정(측면이 아니면 필수) — 카메라를 고정한 뒤, 타격 위치와 그 앞 1~2m(타깃 방향)에 공을 하나씩 바닥에 놓고 [카메라 각도 보정] → ① 타격 위치 공 → ② 앞쪽 공 순서로 탭하세요. 카메라를 옮기면 다시 보정합니다. (설정의 '카메라↔공 거리'는 ① 공까지의 직선거리)
클럽 자동 — 공 아래에 티가 보이면 드라이버, 바닥에 놓인 공이면 7번 아이언으로 계산합니다(스핀 측정 실패 시 기본 스핀·스핀 탐색 범위에 사용).
스핀 측정(딤플) — 공 표면의 딤플·로고 무늬가 프레임마다 어떻게 돌았는지로 3축 회전(백·사이드·라이플)을 계산합니다. 조건: 공 지름이 화면에서 60px 이상(카메라를 가까이), 노출을 짧게(밝은 조명), 그리고 fps가 높을수록 큰 스핀까지 측정됩니다(대략 fps×12 rpm까지, 예: 500fps → 6000rpm). 딤플이 잘 안 보이면 공에 검은 점·선을 몇 개 그리면 훨씬 안정적입니다.
OTG USB 카메라가 목록에 없나요? 대부분의 안드로이드 폰은 USB 카메라를 브라우저에 보여주지 않습니다. 폰 스크린골프 안드로이드 앱(APK)으로 열면 USB 카메라를 직접 연결해 사용할 수 있습니다.
휴대폰의 슬로모션 촬영(240/960 fps) 영상을 분석합니다. 카메라 설치 조건은 실시간 모드와 같습니다. 임팩트 전 공이 정지해 있는 장면부터 시작하는 짧은 클립이 가장 정확합니다.
0 = 파일 시간 그대로
스핀 부호: 백스핀(X축) +는 공이 뜨는 방향, 사이드스핀(Z축) +는 오른쪽으로 휘는 방향(오른손잡이 기준 페이드/슬라이스), 라이플(Y축)은 진행 방향 축 회전(궤적 영향 거의 없음).
